radarhunter_kr · 시행일 2026-08-20

1. 요약

radarhunter_kr은 방문자·시청자의 개인정보를 수집하지 않습니다. 운영자가 사용하는 자동화 도구는 1인용 비공개 도구로, 운영자 본인 소유 계정에만 연결되며 제3자 이용자를 받지 않습니다.

2. 처리하는 정보

구분내용보관 위치
운영자 계정 인증정보 운영자 본인의 TikTok·Instagram 계정에 게시하기 위한 OAuth 액세스/리프레시 토큰, 계정 식별자 운영자 개인 컴퓨터의 로컬 파일. 외부 서버로 전송하지 않음

3. 수집하지 않는 것

본 채널은 이름, 이메일, 전화번호, 주소, 결제정보, 위치정보, 기기식별자, 광고식별자를 일절 수집하지 않습니다. 회원가입 기능이 없으며, 링크 페이지에 로그인·입력 양식이 없습니다.

4. 쿠키 및 통계

링크 페이지는 클릭 수 집계를 위해 GoatCounter를 사용할 수 있습니다. GoatCounter는 쿠키를 사용하지 않고 개인을 식별하지 않으며, 페이지별 익명 집계만 기록합니다. 사용 시 해당 사실이 페이지에 표시됩니다.

5. 제3자 제공

운영자는 어떠한 정보도 제3자에게 판매·제공하지 않습니다. 상품 링크를 클릭하면 해당 쇼핑몰(쿠팡, 토스쇼핑 등)로 이동하며, 이후의 정보 처리는 각 쇼핑몰의 개인정보처리방침을 따릅니다.

6. 플랫폼 API 이용

운영자는 TikTok Content Posting API 및 Instagram Graph API를 통해 운영자 본인 계정에만 콘텐츠를 게시합니다. 이 과정에서 획득한 토큰은 게시 목적으로만 사용하고, 다른 이용자의 데이터에는 접근하지 않으며, 연동 해제 시 로컬에 저장된 토큰을 즉시 삭제합니다.

7. 보관 및 파기

인증 토큰은 연동이 유지되는 동안만 보관하며, 만료·해지 시 파기합니다. 제작한 미디어는 운영자가 보관하며, 게시 취소 시 각 플랫폼에서 삭제합니다.

8. 문의

개인정보 관련 문의는 Instagram @radarhunter_kr 다이렉트 메시지로 받습니다.

Privacy Policy

radarhunter_kr · Effective 2026-08-20

1. Summary

radarhunter_kr does not collect personal information from visitors or viewers. The automation tool used by the Operator is a private, single-user tool. It connects only to accounts the Operator personally owns and accepts no third-party users.

3. What we do not collect

We collect no names, email addresses, phone numbers, postal addresses, payment details, location data, device identifiers or advertising identifiers. There is no sign-up, and the link page contains no login or input forms.

4. Cookies and analytics

The link page may use GoatCounter to count clicks. GoatCounter uses no cookies and does not identify individuals; it records only anonymous per-page counts. Where used, this is stated on the page.

5. Sharing with third parties

The Operator does not sell or share any information with third parties. Clicking a product link takes you to the relevant marketplace (Coupang, Toss Shopping and others), after which that marketplace's own privacy policy applies.

6. Use of platform APIs

The Operator uses the TikTok Content Posting API and the Instagram Graph API to publish content solely to the Operator's own accounts. Tokens obtained in this process are used only for publishing, are never used to access any other user's data, and are deleted from local storage immediately upon disconnection.

7. Retention and deletion

Authentication tokens are retained only while the connection is active and are destroyed on expiry or disconnection. Created media is retained by the Operator and removed from each platform if a post is withdrawn.

8. Contact

Privacy enquiries may be sent by direct message to @radarhunter_kr on Instagram.
